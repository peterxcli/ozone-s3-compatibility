# Parquet Viewer Runtime

The Parquet viewer runtime is built from source vendored from XiangpengHao/parquet-viewer 0.1.31 into this repository's `parquet-viewer/` package.

Use `npm --prefix site run build:parquet-viewer` to rebuild these runtime assets after changing the vendored viewer source.
